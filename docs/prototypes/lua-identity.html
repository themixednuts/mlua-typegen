What is a Lua-visible name when the name is awkward?

This lab compares three identity models across aliases, nested tables, punctuation, collisions, byte strings, and path-traversal names. The question is whether one canonical segmented identity—separate from annotation spelling and files—matches the runtime semantics without making generated output unsafe.

Recommendation to react to

Choose canonical path segments. Store exact Lua string bytes per segment, derive a reversible internal annotation id, render bracket access with a byte-safe Lua literal, and write every compiler unit to one fixed report filename. Reopening a module may merge compatible members; incompatible contributions at one canonical path are a typed collision. One Rust type registered at two paths is two valid Lua identities.
